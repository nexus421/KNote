KNote created this sheet on its first start, so there is something to look at. It shows what a sheet can contain.
Edit or delete it in the admin area, it will not come back.

## What KNote does

* Every sheet lives at its own address, this one at `/example`
* A sheet can have its own password, then it is stored encrypted
* Creating, editing and deleting needs an admin login
* Every sheet can be downloaded as Markdown, see the link below

## Quotes and code

```bash

```
